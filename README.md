# Передача

Сайт для обмена сообщениями, файлами и фото между пользователями (регистрация/вход, чаты, превью фото, публичные ссылки на файлы).

- Node.js + Express, PostgreSQL (таблицы с префиксом `fd_`, файлы хранятся в `bytea`).
- Лимит файла — 20 МБ.
- Переменные окружения: `DATABASE_URL`, `SESSION_SECRET`, опционально `MAX_TOTAL_MB` (общий лимит хранилища, по умолчанию 700).

Запуск: `npm install && npm start`.
